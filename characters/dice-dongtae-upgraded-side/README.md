# DICE: upgraded Dongtae, side view

`character.svg` and `puppet_rig.py` are unchanged snapshots of the existing
DICE artwork and controller. Their original paths and SHA-256 hashes are in
`provenance.json`. Keep this asset separate from the illustrated hoodie rigs.

Use the [DICE adapter](../../docs/dice-character-adapter.md) for scene rendering.
Changes to poses belong in that adapter, not in these saved drawings. A changed
snapshot fails registration checks; do not update its hash to hide an edit.
